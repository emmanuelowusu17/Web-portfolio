Keep Learning: Free Sources

MDN Web Docs: Learn Web Development

Free lessons on HTML and CSS from Mozilla, the makers of Firefox. Used for the HTML and CSS pages.

https://developer.mozilla.org/en-US/docs/Learn_web_development

Bootstrap 5.3 Documentation

The official guide, with copy-and-paste examples of every component. Used for the Bootstrap page.

https://getbootstrap.com/docs/5.3/getting-started/introduction/

Pro Git (free book)

The official Git book, free to read online. Chapters 1 and 2 cover everything a beginner needs. Used for the Git page.

https://git-scm.com/book/en/v2

GitHub Docs: Get Started

GitHub's official guide to repositories, commits, and pushing your code. Used for the GitHub section.

https://docs.github.com/en/get-started

GitHub Pages Quickstart

Step-by-step directions for publishing a website from a GitHub repository. Used for the publishing steps.

https://docs.github.com/en/pages/quickstart

freeCodeCamp

Free hands-on coding lessons and projects you complete in the browser. A good next step after this toolkit.

https://www.freecodecamp.org/
