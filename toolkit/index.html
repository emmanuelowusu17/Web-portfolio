Start Building Websites

A beginner's guide to the tools every new web developer uses: HTML, CSS, Bootstrap, Git, and GitHub. Learn what each one does, see real code, and publish your first website for free.

Who This Is For

This toolkit is for anyone who is new to software engineering, or anyone with a passion for building things who doesn't know where to start. You don't need a computer science degree, and every tool here is free.

How the Tools Fit Together

Think of building a website like building a house:

🧱

HTML is the frame

It builds the structure: the headings, paragraphs, images, and links.

🎨

CSS is the paint

It controls how things look: colors, fonts, spacing, and layout.

🛋️

Bootstrap is ready-made furniture

It gives you pre-built pieces, like menus and cards, so you don't build everything from scratch.

📸

Git is the photo album

It saves a snapshot of your project each time you finish a change, so you can always go back.

☁️

GitHub is the online storage

It keeps a copy of your project online, where you can share it and even host it as a live website.

Your Learning Path

Follow the steps in order. Each one builds on the last.

  1. 1

    Learn HTML

    Write the structure and content of a web page.

  2. 2

    Style it with CSS

    Add colors, fonts, and spacing to your page.

  3. 3

    Build faster with Bootstrap

    Make your page work on phones and laptops with ready-made layouts.

  4. 4

    Save and share with Git & GitHub

    Track your changes, put your code online, and publish your site for free.

Set Up Your Free Tools

All of these tools are free. Install them before you start the lessons.
Tool What it does Where to get it
A web browser Shows your web pages. Chrome, Firefox, Edge, and Safari all work. You probably already have one
Visual Studio Code A code editor: the app where you write your HTML and CSS. code.visualstudio.com
Live Server A VS Code extension that opens your page in the browser and refreshes it every time you save. In VS Code, open the Extensions panel and search "Live Server"
Git Tracks the changes to your project on your computer. git-scm.com/downloads
A GitHub account Stores your projects online and can host your website. github.com

Ready to start?

Begin with HTML. By the end of the toolkit, you'll have a real website online.
