Build Faster with Bootstrap

Bootstrap gives you ready-made styles, so your site looks good on phones and laptops without writing all the CSS yourself.

What Is Bootstrap?

Bootstrap is a free CSS framework: a big CSS file that someone else already wrote, full of ready-made classes. Instead of writing CSS for a button, you add class="btn btn-primary" to your HTML and it's styled. Bootstrap is also responsive, which means its layouts change to fit the screen size.

Add Bootstrap to Your Page

You don't need to download anything. Paste these two lines inside your <head>. They load Bootstrap from a CDN, a fast public server that hosts files for websites.

index.html
<!-- Bootstrap's CSS: the styles -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">

<!-- Bootstrap's JavaScript: makes menus and other interactive parts work -->
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>

<!-- Your own CSS goes AFTER Bootstrap, so your styles win -->
<link rel="stylesheet" href="style.css">

The Grid: Layouts That Fit Any Screen

Bootstrap splits each row into 12 equal columns. You choose how many of the 12 each box takes up. Every grid has three parts: a container that holds everything, a row, and col boxes inside the row.

index.html
<div class="container">
    <div class="row">
        <div class="col-md-4">Box 1</div>
        <div class="col-md-4">Box 2</div>
        <div class="col-md-4">Box 3</div>
    </div>
</div>

Each row adds up to 12. On a phone, every box takes the full width and they stack.

What does "md" mean?

The middle part of col-md-4 is a breakpoint: the screen width where the layout switches. Below that width, the columns stack.

The main Bootstrap 5 breakpoints and the screens they're for.
Breakpoint Class example Side by side when the screen is at least Typical device
Small col-sm-6 576px Large phone
Medium col-md-6 768px Tablet
Large col-lg-6 992px Laptop
Extra large col-xl-6 1200px Desktop monitor

Utility Classes: Small Styles, No CSS

Utility classes each do one small job. You can stack several on one element.

Spacing sizes go from 0 (none) to 5 (largest).
Class What it does
mt-3 margin on the top, size 3. Also: mb (bottom), ms (start/left), me (end/right).
p-4 padding on all sides, size 4
text-center Centers the text
bg-primary, text-white Blue background, white text
d-none d-md-block Hidden on small screens, shown from medium screens up
img-fluid Shrinks an image so it never gets wider than its box
The Bootstrap docs are your best friend. Every component has an example you can copy. Professional developers look things up all the time. You don't need to memorize every class.
