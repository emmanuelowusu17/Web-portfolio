Save and Share with Git & GitHub

Git saves every version of your project. GitHub puts it online, where you can share it and publish it as a real website.

Git vs. GitHub

They sound alike, but they're two different things that work together.

💻

Git

A version control tool that runs on your computer. Each time you finish a change, Git saves a snapshot called a commit. If something breaks, you can go back to an earlier version.

☁️

GitHub

A website that stores your Git projects online. It works as a backup, lets other people see and work on your code, and can host your site for free with GitHub Pages.

Words to Know

You'll see these words every time you use Git and GitHub.
Word What it means
Repository (repo) A project folder that Git is tracking, along with its full history of changes
Commit A saved snapshot of your project, with a short message describing what changed
Branch A separate line of work. The main one is usually called main.
Push Send your commits from your computer up to GitHub
Pull Bring the newest commits from GitHub down to your computer
Clone Download a full copy of a repository from GitHub to your computer

One-Time Setup

After installing Git, open a terminal (in VS Code: Terminal > New Terminal) and tell Git who you are. Use the same email as your GitHub account.

Terminal
git config --global user.name "Your Name"
git config --global user.email "you@example.com"

Put Your First Project on GitHub

  1. On GitHub, click New to create a repository. Give it a name, like my-first-site, and click Create repository.
  2. Copy the repository's web address. It looks like https://github.com/your-username/my-first-site.git.
  3. In VS Code, open your project folder, open the terminal, and run these commands one at a time:
Terminal
# Start tracking this folder with Git (only once per project)
git init

# See which files changed
git status

# Stage all your changes (the dot means "everything in this folder")
git add .

# Save a snapshot with a message that describes the change
git commit -m "Add home page"

# Name your main branch "main"
git branch -M main

# Connect your folder to the GitHub repository (paste your own address)
git remote add origin https://github.com/your-username/my-first-site.git

# Upload your commits to GitHub (-u remembers where to push next time)
git push -u origin main

Your Everyday Routine

After the first push, every change follows the same 4 steps:

  1. Edit your files and save them.
  2. git add . to stage the changes.
  3. git commit -m "Describe the change" to save a snapshot.
  4. git push to upload it to GitHub.

Write Good Commit Messages

A good message tells your future self what changed. Start with a verb.

  • Good Add contact form to about page
  • Good Fix broken image link on home page
  • Bad stuff
  • Bad changes

Publish Your Site with GitHub Pages

GitHub Pages turns your repository into a live website for free. This toolkit is hosted the same way.

  1. On GitHub, open your repository and click Settings.
  2. In the left menu, click Pages.
  3. Under Build and deployment, set the source to Deploy from a branch.
  4. Choose the main branch and the / (root) folder, then click Save.
  5. Wait a few minutes (it can take up to 10). Your site will be live at https://your-username.github.io/my-first-site/.
Prefer buttons over typing? VS Code has a Source Control panel on the left side. It can stage, commit, and push with clicks. Learning the commands first helps you understand what those buttons are doing.
