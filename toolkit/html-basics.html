Learn HTML

HTML is the language that builds the structure of every web page you visit.

What Is HTML?

HTML stands for HyperText Markup Language. It isn't a programming language that does math or makes decisions. Instead, it marks up your content, telling the browser "this is a heading," "this is a paragraph," or "this is a link." You write HTML in a plain text file that ends in .html, and the browser turns it into a web page.

The Parts of an HTML Element

An element is one piece of a page, like a link. Most elements have an opening tag, content, and a closing tag.

example.html
<a href="https://github.com">Visit GitHub</a>
Each part of the link element above.
Part In the example What it does
Opening tag <a ...> Starts the element. a stands for "anchor," which means a link.
Attribute href="https://github.com" Adds extra information. href is where the link goes.
Content Visit GitHub What the visitor sees and clicks.
Closing tag </a> Ends the element. It has a slash (/) before the name.

The Basic Page Structure

Every HTML page starts with the same skeleton. Copy it to start any new page.

index.html
<!DOCTYPE html>
<html lang="en">
    <head>
        <meta charset="utf-8">
        <meta name="viewport" content="width=device-width, initial-scale=1">
        <title>My First Page</title>
    </head>
    <body>
        <h1>Hello, world!</h1>
        <p>This is my first web page.</p>
    </body>
</html>
  1. <!DOCTYPE html> tells the browser this is a modern HTML page.
  2. <html lang="en"> wraps the whole page. lang="en" says it's in English, which helps screen readers.
  3. <head> holds information about the page that visitors don't see on the page itself.
  4. <title> is the name shown on the browser tab.
  5. <body> holds everything visitors see: text, images, and links.

Common HTML Tags

You'll use these tags on almost every page you build.
Tag What it's for Example
<h1> to <h6> Headings, from most important (h1) to least important (h6) <h1>My Portfolio</h1>
<p> A paragraph of text <p>Hi, I'm a student.</p>
<a> A link to another page <a href="about.html">About</a>
<img> An image. It has no closing tag. alt describes the image for people who can't see it. <img src="me.jpg" alt="Photo of me">
<ul>, <ol>, <li> A bulleted list, a numbered list, and the items inside them <ul><li>HTML</li></ul>
<div> A general box for grouping other elements, often for styling <div class="card">...</div>
<nav>, <main>, <section>, <footer> Named areas of the page. Called semantic tags because their names describe their meaning. <footer>&copy; 2026</footer>

Try It Yourself

  1. Make a new folder on your computer called my-first-site.
  2. Open VS Code, then choose File > Open Folder and pick that folder.
  3. Create a new file called index.html. The home page of a website is usually named this.
  4. Type ! and press Enter. VS Code fills in the whole page skeleton for you.
  5. Inside <body>, add an <h1> with your name and a <p> about yourself.
  6. Right-click the file and choose Open with Live Server to see your page in the browser.

Good Habits

  • Use only one <h1> per page, and keep headings in order (h1, then h2, then h3).
  • Give every image an alt description.
  • Indent elements that sit inside other elements, so the structure is easy to read.
  • Leave notes with comments: <!-- like this -->. Browsers don't show them.

Common Mistakes

  • Forgetting a closing tag. A missing </p> or </div> can break the layout below it.
  • Missing quotes. Attribute values go in quotes: href="about.html".
  • Wrong file path. If an image doesn't show, check the spelling and the folder in src.
  • Not saving. The browser only shows the last version you saved.
