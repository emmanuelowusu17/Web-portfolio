Style It with CSS

CSS controls how your page looks: the colors, fonts, spacing, and layout.

What Is CSS?

CSS stands for Cascading Style Sheets. HTML decides what is on the page, and CSS decides how it looks. You write your styles in a separate file that ends in .css, then connect it to your HTML page with a <link> tag inside <head>:

index.html
<link rel="stylesheet" href="style.css">

"Cascading" means that when two rules style the same thing, the one that comes later (or is more specific) wins. That's why your own CSS file should be linked after Bootstrap.

The Parts of a CSS Rule

style.css
h1 {
    color: navy;
    font-size: 40px;
}
  • Selector (h1): which elements to style.
  • Curly braces ({ }): hold all the styles for that selector.
  • Property (color): what you want to change.
  • Value (navy): what to change it to.
  • Semicolon (;): ends each line. Forgetting one is the most common CSS mistake.

Choosing What to Style: Selectors

The three selectors you'll use most.
Selector In the CSS In the HTML What it styles
Element p { } <p> Every paragraph on the page
Class (starts with a dot) .card { } <div class="card"> Every element with that class. You can reuse a class many times.
ID (starts with #) #header { } <div id="header"> One single element. Each ID can only be used once per page.

Tip: use classes for most of your styling. They're reusable and easy to manage.

Common CSS Properties

Properties you'll use on almost every page.
Property What it changes Example
color Text color color: #05142d;
background-color The color behind an element background-color: white;
font-family The font. List backups in case the first isn't installed. font-family: Arial, sans-serif;
font-size Text size font-size: 18px;
text-align Lines up text left, right, or center text-align: center;
padding Space inside an element, around its content padding: 16px;
margin Space outside an element, between it and its neighbors margin: 24px;
border A line around an element: its width, style, and color border: 2px solid blue;
border-radius Rounds the corners border-radius: 10px;

The Box Model

The browser treats every element as a box made of four layers, from the inside out:

  1. Content: the text or image itself.
  2. Padding: space between the content and the border.
  3. Border: the line around the padding.
  4. Margin: space outside the border that pushes other elements away.

Try It Yourself

Create a file called style.css next to your index.html, link it, and paste this in. Then change the values and watch what happens.

style.css
/* This is a CSS comment. The browser ignores it. */
body {
    font-family: Arial, sans-serif;
    background-color: #f4f7fb;
}

h1 {
    color: #05142d;
    text-align: center;
}

.card {
    background-color: white;
    border: 2px solid #0a58ca;
    border-radius: 10px;
    padding: 16px;
    margin: 24px;
}
Use your browser's Developer Tools. Right-click anything on a page and choose Inspect. You'll see its HTML and CSS, and you can change the styles live to test ideas. Nothing you change there is saved, so you can't break anything.
